# GitHub da reversa: Entrenará su IA con tu código a partir del 24 de abril

**GitHub acaba de anunciar un cambio de política que tiene a la comunidad de desarrolladores furiosa.** A partir del 24 de abril de 2026, tu código será usado para entrenar modelos de IA — a menos que explícitamente hagas opt-out.

## El cambio de postura

Hace meses, GitHub prometió no usar código privado para entrenar Copilot y otros modelos. Ahora, The Register reporta que dieron un giro de 180 grados:

> "Cross-signed code gets the cold shoulder as Redmond tightens trust"

Traducción: Microsoft quiere más datos para entrenar sus modelos, y tu repositorio está en la mira.

## ¿Qué significa para ti?

Si tienes código en GitHub — privado o público — esto te afecta:

1. **Código propietario** podría terminar en modelos de IA
2. **Snippets y patrones** de tu trabajo aparecerán en sugerencias de otros
3. **Proyectos comerciales** podrían estar en riesgo

## Cómo proteger tu código

**Antes del 24 de abril:**

1. Ve a Settings → Copilot
2. Desactiva "Allow GitHub to use my code snippets for product improvements"
3. Considera mover proyectos sensibles a alternativas (GitLab, Gitea)

## La ironía de la situación

GitHub se convirtió en el estándar de la industria porque los desarrolladores confiaron en la plataforma. Ahora, esa confianza se está usando para alimentar productos de IA que compiten directamente con los desarrolladores.

**Mi recomendación:** Si tienes IP valiosa en GitHub, haz opt-out HOY. No esperes al deadline.
