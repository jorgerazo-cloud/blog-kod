**Bruce Perens, uno de los fundadores del movimiento Open Source**, acaba de lanzar una advertencia que debería preocupar a toda la industria del software: **la IA generativa está haciendo imposible el cumplimiento de licencias**.

## ¿Quién es Bruce Perens?

Para quien no lo conozca:

- **Cofundador** del movimiento Open Source
- **Autor** de la Open Source Definition
- **Líder** del proyecto Debian
- **Voz respetada** en la comunidad de software libre

Cuando Perens habla, la industria escucha.

## El problema: Chardet y la disputa que lo explica todo

El caso que desató la alarma involucra a **Chardet**, una biblioteca de detección de codificación de caracteres. El escenario:

1. Un modelo de IA fue entrenado con código de Chardet
2. La IA genera código "nuevo" que es funcionalmente idéntico
3. **¿Quién es responsable?** ¿El modelo? ¿El usuario? ¿El creador del código original?

> "Las alarmas están sonando en la comunidad open source, pero las licencias comerciales también están en riesgo."
> — Bruce Perens

![Código generado por IA vs código original](/images/posts/ai-code-licensing-comparison.webp)

## Por qué las licencias están muriendo

El modelo tradicional de licencias asume:

| Antes | Ahora con IA |
|-------|-------------|
| Humano copia código | IA "aprende" y regenera |
| Atribución clara | Origen imposible de rastrear |
| Violación detectable | Código "nuevo" pero derivado |
| Responsabilidad individual | Cadena difusa de responsabilidad |

## Impacto en tres frentes

### 1. Open Source
- **GPL, MIT, Apache** — ¿Cómo se aplican a código regenerado?
- **Atribución** — Imposible saber qué código "inspiró" el output
- **Copyleft** — ¿El código generado "hereda" la licencia?

### 2. Software Comercial
- **Licencias propietarias** — Código comercial en datasets de entrenamiento
- **Trade secrets** — Algoritmos "aprendidos" y reproducidos
- **Indemnización** — ¿Quién paga cuando hay demanda?

### 3. Desarrolladores
- **Responsabilidad personal** — ¿Eres culpable si usas código de IA?
- **Due diligence** — Imposible verificar el origen
- **Contratos laborales** — Cláusulas de IP obsoletas

## ¿Hay solución?

Perens y otros expertos proponen:

1. **Nuevos marcos legales** — Legislación específica para IA
2. **Licencias actualizadas** — Versiones "AI-aware" de GPL/MIT
3. **Transparencia en entrenamiento** — Revelar datasets
4. **Herramientas de detección** — Identificar código derivado

## Para empresas mexicanas

Si desarrollas software o usas IA para coding:

⚠️ **Revisa tus políticas** de uso de código generado
⚠️ **Documenta** el origen de tu código
⚠️ **Consulta legal** antes de lanzar productos con código de IA
⚠️ **Mantente informado** — Esto está evolucionando rápido

## El futuro incierto

La ironía: la IA que prometía democratizar el desarrollo de software podría terminar **paralizándolo** por incertidumbre legal.
